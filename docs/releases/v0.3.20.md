# ToolTrust Scanner v0.3.20 / npm tooltrust-mcp 1.1.13

### Added
- Detect Rust MCP server presence for rmcp ServerHandler implementations and handwritten serde_json tools/list handlers. Ignore comments and string examples. This is presence detection, not complete Rust schema extraction.
- Run CLI/MCP user-path verification in CI, including pagination, empty discovery, OSV failures and release packaging checks.
- Refresh reviewed malicious-package intelligence accumulated since v0.3.19.

### Fixed
- Empty tool manifests and live discovery now fail explicitly instead of receiving a clean A. Gate cannot bypass missing discovery with --force.
- Failed OSV lookups, invalid responses, timeouts and partial dependency lookup failures now report scan incomplete. MCP returns tool errors and gate refuses installation.
- Update the Go toolchain to 1.26.9 and golang.org/x/text for security fixes.
- Preserve npm wrapper failure exits when a cached binary cannot start, and support an isolated cache via TOOLTRUST_CACHE_DIR.
- Align npm tooltrust-mcp 1.1.13 and registry metadata with scanner v0.3.20; the previous npm wrapper still selected v0.3.17.

### Upgrade notes
- Scripts must handle nonzero exit when discovery is empty or OSV is unavailable. No success report is produced for these incomplete scans; a pre-existing output file is not evidence of a successful new run.
- TOOLTRUST_OSV_URL can select a trusted OSV-compatible endpoint (HTTPS, or numeric loopback HTTP for testing). Dependency names and versions are sent to that endpoint.
- MCP HTTP transport, full Rust schema extraction and Cargo dependency scanning remain outside this release.
